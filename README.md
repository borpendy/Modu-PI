The Modu-PI project is an experimental modular Rasberry PI architecture, aimed at handheld device development. The Modu-PI board contains the essentials required for handheld use of the rasberry pi CM5 module. These include an onboard BMS, Coulomb counter and PD trigger, to allow for battery charging and operation. Additionally, the board features 2 DSI ports (22 pin form factor), an SD Slot, and a modular expansion slot (22 Pin custom layout) for additional daughterboards. An stm32 is included as the onboard MCU, for battery and power management.
